# La Calculadora Más Pequeña del Mundo

Una calculadora interactiva minúscula en Python: una sola línea de código Python.

## Inicio rápido

Puedes pegar esto en una terminal si tienes Python instalado:

```
python -c "while 1:print(eval(input()))"
```

O descarga el repositorio y ejecuta el archivo:

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

Luego escribe cualquier expresión y presiona Enter para evaluarla.
