# 世界上最小的计算器

一个超简洁的交互式 Python 计算器——只有一行 Python 代码。

## 快速开始

如果你已经安装了 Python，可以直接在终端中粘贴运行：

```
python -c "while 1:print(eval(input()))"
```

或者下载仓库并运行该文件：

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

然后输入任意表达式并按回车键即可计算。
