# 세계에서 가장 작은 계산기

매우 작은 대화형 Python 계산기 — 단 한 줄의 Python 코드입니다.

정말 단 한 줄입니다.

## 빠른 시작

Python이 설치되어 있다면 터미널에 이것을 붙여넣을 수 있습니다:

```
python -c "while 1:print(eval(input()))"
```

또는 저장소를 다운로드하고 파일을 실행하세요:

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

그런 다음 아무 표현이나 입력하고 Enter 키를 눌러 계산하세요.
