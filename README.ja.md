# 世界一小さい電卓

とても小さな対話型 Python 電卓 — Python コードはたった 1 行です。

本当に 1 行だけです。

## クイックスタート

Python がインストールされていれば、ターミナルにこれを貼り付けることができます：

```
python -c "while 1:print(eval(input()))"
```

またはリポジトリをダウンロードしてファイルを実行します：

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

その後、任意の式を入力して Enter キーを押すと計算されます。
