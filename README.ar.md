# Worlds-Smallest-Calc

آلة حاسبة تفاعلية صغيرة بلغة بايثون — سطر واحد فقط من كود بايثون.

إنها حقاً سطر واحد فقط.

## بداية سريعة

يمكنك لصق هذا في الطرفية إذا كانت بايثون مثبتة لديك:

```
python -c "while 1:print(eval(input()))"
```

أو قم بتنزيل المستودع وشغّل الملف:

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

ثم اكتب أي تعبير واضغط على Enter لتقييمه.
