# Самая маленькая в мире вычислительная машина

Крошечный интерактивный калькулятор на Python — одна строка кода Python.

Да, это действительно всего одна строка.

Поддерживаются любые выражения Python: арифметика, переменные и встроенные функции.

## Быстрый старт

Если у вас установлен Python, вы можете вставить это в терминал:

```
python -c "while 1:print(eval(input()))"
```

Или скачайте репозиторий и запустите файл:

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

Затем введите любое выражение и нажмите Enter, чтобы его вычислить.
