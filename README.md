# Worlds-Smallest-Calc

A tiny interactive Python calculator — a single line of Python code.

## Quick start

You can paste this into a terminal if you have Python installed:

```
python -c "while 1:print(eval(input()))"
```

Or download the repo and run the file:

```
gh repo clone lllons/Worlds-Smallest-Calc
cd Worlds-Smallest-Calc
python Calc.py
```

Then type any expression and press Enter to evaluate it.
