## Worlds smallest calc

Most likely the smallest possible calc achievable with plain Python code. 
Probably shouldn't be used in production.

Quick start for those that don't know python.

You can just copy and paste this into terminal if you have python installed.
```
python -c "while 1:print(eval(input()))"
```
Or if you want the repo downloaded

```
gh repo clone lllons/Worlds-Smallest-Calc
```
Then..
```
cd Worlds-Smallest-Calc
```
Then...
```
python run Calc.py
```
